\note{2}{Wed 17 Apr 2024 15:49}{Counterexamples}

Banach subspaces that are not closed:
\begin{enumerate}
	\item Algebraic span of a countably infinite linear independent set is not closed.
\end{enumerate}

Closed, bounded subsets of a normed space that are not compact:
\begin{enumerate}
	\item The closed unit ball is not compact, if it's in infinite dimension.
	\item For a closed-bounded set to be compact, it needs to be almost finite-dimensional.
\end{enumerate}
