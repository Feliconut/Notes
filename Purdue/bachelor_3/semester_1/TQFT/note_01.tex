\note{1}{Tue 26 Sep 2023 19:43}{Matrix representation matrix multiplication}


We want to solve
\[
	A B = C A
.\] 
Where $A \in \operatorname{Hom}(V, W), B \in \operatorname{End}(V), C \in \operatorname{End}(W)$.

Let $n = \operatorname{dim} V$, $m = \operatorname{dim} W$.

We represent the left and right multiplications of $B$ and $C$ as matrix acting on vector $A$. Then we only need to solve
\[
	\mathcal{M}_r(B) \mathcal{V}(A) = \mathcal{M}_l (C) \mathcal{V}(A)
.\] 

The functions $\mathcal{M}_r, \mathcal{V}$ need to make the following diagram commute for all $B \in \text{End}(V, V)$, and $M_l, \mathcal{V}$ need to make the following diagram commute for all $B \in \text{End}(W, W)$.
