\section{Simple Problem}
We begin with a relaxed problem of best selection with no error. Let $[x,n]$ denote the initial game state where we have an upcoming item with value $x$ and $n$ un-observed items after the current item.

If the player accepts the first item, he wins iff all other items are less than the first item. Hence $\operatorname{Pr}\left[{\text{win} | \text{accept at } [x,n]}\right] = x^{n}$.  
If the player declines $x$, he wins iff he wins the sub-game $[x_{n-1}, n-1]$, and $\max(x_{n-1}, \ldots, x_1) < x$. We denote the new game state by $[x_{n-1}, n-1, x]$.

Let $V(x,n,x^*) := \operatorname{Pr}\left[{\text{win starting from} [x,n] \cap \max\left( x, x_n, \ldots, x_0 \right) > x^*}\right] $. From principle of dynamic programming, the optimal policy can be yielded from the following system of equations:
\begin{align*}
	V(x, 0, x^*) &= \textbf{1}(x>x^*)\\
	V(x, n, x^*) &= \begin{cases}
		\max\left( x^n,   EV(\cdot,n-1, x)\right) &x\ge x^*\\
		EV(\cdot, n-1, x^*) &x<x^*
	\end{cases}
.\end{align*}

Our first observation is that a thresholding scheme can be optimal.

\begin{theorem}
	There exists a sequence $T_n \subset \R$ such that $ x^n>  EV(\cdot,n-1, x)\iff x > T_n$ for all $n \in  \N$. 
\end{theorem}
\begin{proof}
	The LHS of the inequality monotonically increase wrt $x$, while the RHS monotonically decrease wrt $x$. Hence the solution set is in the form $(T_n, 1]$.
\end{proof}

We can also say something about $T_n $:

\begin{theorem}
	The optimal thresholding sequence $T_n$ has the following properties:
	\begin{enumerate}
		\item $T_0 = 0 $ and $T_1 = \frac{1}{2}$
		 \item $T_n$ strictly monotonically increase.
		\item  $\lim_{n \to \infty} T_n = 1$
	\end{enumerate}
\end{theorem}

\section{Relaxed Problem with Error}
Fix $\delta > 0$, and use the following notation for game state: $[\tilde x, n]$ means the current item to be decided has observed (inaccurate) value  $\tilde x$, and we have $n$ items after the current item. 
If the player examines the current item, the game state evolves into $[x, n-1]$, where we now have the exact value $x$, and one item (the next) is omitted. 
If the player otherwise declines the current item, the game state evolves into $[\tilde x_n, n-1]$ where $\tilde x$ is replaced by $\tilde x_n$, the next item, and we have one item less in the queue.

We again obtain the DP equations. $a \wedge b$ denotes $\max(a,b)$.
\begin{align}
	\label{base}	V(x, 0, x^*) &= \textbf{1}(x>x^*)\\
	\label{err_induct}V(\tilde x, n, x^*) &= \max\left( EV(X,n-1, x^* \wedge X_{n-1}), EV(\tilde X_{n-1}, n-1, x^* \wedge X)\right)  \\
	\label{noerr_induct}V(x, n, x^*) &=  \begin{cases}
	\max\left( x^n,  \expect{V(\tilde X_{n-1}, n-1, x)}\right) &x\ge x^*\\
	\expect{V(\tilde X_{n-1}, n-1, x^*)} &x<x^*
	\end{cases}
.\end{align}

The problem with error is again solvable using thresholding:
\begin{theorem}
	The optimal policy for the problem with error can be described completely by thresholding. In other words, for each $\delta \ge 0$, there exists sequences $T_n$ and $R_n \in \R$ such that the LHS in the $\max$ operator of \eqref{err_induct} is greater than the RHS iff $\tilde x > R_n$. Similarly, the LHS is picked in \eqref{noerr_induct} iff $x > T_n$.
\end{theorem}
\begin{proof}
	We first prove the existence of $T_{n}$. In \eqref{noerr_induct}, note that $ V(\tilde X_{n-1}, n-1, x)$ is monotone decreasing wrt $x$ for each specific realization of $\tilde X_{n-1}$. Taking expectation won't affect monotonicity, so the argument in the previous theorem applies.  
	
	Now we work on existence of $R_{n}$ and consider \eqref{err_induct}. Let $A(x) := \expect{V(x, n-1, x^* \wedge X_{n-1}}$ and $B(x):= \expect{V(\tilde X_{n-1}, n-1, x^* \wedge x)}$, where the expectation is taken over $(u-\delta, u+\delta)\cap (0,1)$. Our goal is to prove that $EA > EB$ is a thresholding on $u$. We will first show that $A(x)>B(x)$ is a thresholding on $x$, and apply properties of expectation.
	
	Let $x < x^*$. Now $A(x) = \expect{V\left( \tilde X_{n-2}, n-2, x^* \wedge X_{n-1} \right) }$ and $B(x) = \expect{V\left( \tilde X_{n-1}, n-1, x^* \right) }$. $B(x)$ is measure of the event that the best item is selected with value $>x^*$, while $A(x)$ is measure of the same event with additional constraint that $X_{n-1}$ is not the best item. Hence $A(x)$ is a sub-event of $B(x)$, and $A(x) < B(x)$.

	Let $x > x^*$ and assume $x < T_{n}$. Now $A(x) = \expect{V\left( \tilde X_{n-2}, n-2, x \wedge X_{n-1} \right) }$ and $B(x) = \expect{V\left( \tilde X_{n-1}, n-1, x \right) }$. By the same argument, $A(x) < B(x)$.
	
	Now assume $x > T_{n}$. Take $\omega \in \Omega$. For all $x < X_{n-1}(\omega)$, we have $A_\omega(x) < B(x)$ (why? Need to clarify). For all $x > X_{n-1}(\omega)$, $A_\omega(x) = x^{n-1}$  monotonically increase up to $A(1) = 1$. Hence we have a unique intersection  $\alpha \in (T_{n}, 1)$ where $x > \alpha \iff A_\omega(x) > B(x)$. $\alpha$ does not depend on $\omega$, so it's the unique intersection between $B(x)$ and the "averaged"  $A(x)$.

	(Another way to proceed) Now assume $x > T_{n}$. Evaluate the expectation over $X_{n-1}$, we have \[
	A(x) = \int_0^x x^{n-1} dy + \int_x^1 EV(\tilde X_{n-2}, n-2, y) \, dy
	.\] 
	As $x$ increases from $T_{n}$ to $1$, the first term monotonically increase from $T_{n}^n$ to $1$, while the second term monotonically decreae and vanishes. $A(x)$ is continuous, so there's at least one intersection. (remains to show uniqueness)
\end{proof}
